# TradeS Agent

**中文名**：外贸客户资料清洗整理 Agent  
**一句话定位**：本地 Web 版「线索数据清洗工作台」  
**目标用户**：外贸软件公司 ToB 销售 / 内部数据清洗同事  
**核心场景**：广交会 / 中国制造 / 阿里巴巴 原始线索 → 武汉某公司规则清洗 → 导入某公司系统外呼

---

## 1. 产品定义

把多渠道客户数据批量清洗成可直接导入**武汉某公司系统**的标准表，减少手工整理表格时间。

| 项 | 内容 |
|----|------|
| 交付形态 | 一键启动的本地 Web 应用（仅 `127.0.0.1`） |
| 页面 | 首页 / 清洗 / 问答 + 设置 |
| 产品形态 | 清洗 Agent + 问答（可选大模型） |
| 数据原则 | 原始表与结果只存本机；清洗用本地规则，不整表送模型 |
| 业务来源 | 2026-09《数据清洗工作记录》（广交会 / 中国制造 / 阿里 → 某公司导入） |

---

## 2. 核心功能

### 2.1 某公司清洗（硬性规则）

| 规则 | 说明 |
|------|------|
| 手机号 | **1 开头 11 位** |
| 号码前缀 | 去掉 `+86` / `86` / `0086` 等 |
| 座机 / 国际号 | 去掉（如 `+853` / `+886` / `+852`） |
| 多号码 | 第 1 → **常用电话**，第 2 → **备用电话1**，第 3 → **备用电话2** |
| 分隔符 | `、 ; / ,` 与多空格 |
| 去重 | **按公司名称**，保留第一条有效记录 |
| 删除 | **无手机号**、**缺公司名** 的记录 |

**导出模板（武汉某公司 18 列）**  
`公司名称、部门、公司网址、网站网址、姓名、岗位、常用电话、备用电话1、备用电话2、性别、生日、微信、钉钉、邮箱、QQ、旺旺、个人传真、淘到客户时间`

**统计**：原始、清洗后、有效率、无手机删除、公司重复、仅座机删除、有备用电话家数。

### 2.2 清洗页

- 上传一个或多个 Excel/CSV，自动合并  
- 自动字段映射，可手动指定  
- **Agent 模式**：一句话指令 → 规划 → 清洗 → 自检轨迹  
- **手动模式**：映射 + 某公司规则（默认）  
- 导出：`{来源}_清洗结果.xlsx` + 按约 **1500 条/表** 写 `分表\`  
- 默认输出：`桌面\清洗\`（`app/config.json` 可改）

### 2.3 问答页

- 多轮对话、流式回答、Markdown 渲染  
- **联网搜索**（可选，检索结果并入上下文）  
- **附件**：txt/csv/md/json 等文本摘要并入提问  
- **历史对话**：列表切换、单条删除、清空  
- 导出 Markdown 问答记录  
- 大模型未配置时使用本地知识库（清洗规则 / 操作指导）

### 2.4 界面

- 深色主题 + **蓝白科技风明亮主题**，顶栏一键切换  
- 玻璃卡片、点击涟漪、鼠标蓝色光感跟随  
- 线性 SVG 图标与科技感品牌 Logo  

### 2.5 验收口径

- 手机号均为 1 开头 11 位  
- 至少「公司名称 + 有效常用电话」  
- 无座机、无重复公司  
- 可直接导入武汉某公司系统

## 3. 启动与使用

1. 双击 `app\启动.bat`  
2. 命令行显示 `http://127.0.0.1:8787`，浏览器自动打开  
3. 「清洗」上传表格 → Agent 指令或手动模式 → 导出 Excel  
4. 「问答」提问；「设置」配置大模型  

**依赖**：Python 3.10+，`pandas`、`openpyxl`（启动脚本可尝试自动安装）。  
**示例数据**：`app\sample_阿里导出.csv`

---

## 4. 配置

### `app/config.json`

| 段 | 作用 |
|----|------|
| `server` | host / port（默认 8787）/ 是否自动开浏览器 |
| `cleaning` | 手机号模式、前缀、国际号、分隔符、模板列、输出目录、分表行数 |

### 大模型（可选）

- OpenAI 兼容；界面「设置」可选预设或自定义  
- 供应商芯片：MiMo / DeepSeek / Kimi / 智谱 / 千问 / 自定义等  
- 保存于 `app/llm_config.json`（**勿外传**）  
- 支持「测试连接」；未配 Key 时问答走本地库，清洗仍可用  

---

## 5. 技术实现

| 层 | 选型 |
|----|------|
| 形态 | 本地 Web，双击启动，绑定 `127.0.0.1` |
| 服务 | Python 标准库 `http.server` |
| 清洗 | pandas + openpyxl（`clean_engine.py`） |
| Agent | `agent_core.py`（指令规划 + 轨迹） |
| 问答 | `qa_store.py` 历史；SSE 流式；联网摘要 |
| 大模型 | `llm_client.py`（多方案、流式、SSL 兼容） |
| 前端 | `app/static/` 无构建（HTML/CSS/JS） |

## 7. 安全与合规

1. API Key 仅存本机配置，不写入前端源码  
2. 仅监听 `127.0.0.1`  
3. 线索数据只在本机处理  
4. 清洗用本地规则；大模型用于问答、映射建议、抽检  
5. 不编造清洗条数；不确定写「待核实」
