# 数据清洗规则（与 Agent / 代码共用）

> 来源：2026-09-13《数据清洗工作记录》· 武汉某公司系统导入

## 1. 手机号

1. 必须是 **1 开头的 11 位**数字（中国大陆手机号）
2. 清除前缀：`+86`、`86`、`0086`
3. 清除座机（区号+号码）
4. 清除国际号码：`+853` 澳门、`+886` 台湾、`+852` 香港等
5. 分隔符：顿号 `、`、分号 `;`、斜杠 `/`、逗号 `,`、多空格
6. 多号码：第 1 个 → **常用电话**，第 2 个 → **备用电话1**，第 3 个 → **备用电话2**

## 2. 记录级

1. 按 **公司名称去重**，保留第一条有效记录
2. **删除无手机号**的记录（导入系统无意义）

## 3. 导出模板（武汉某公司）

`公司名称、部门、公司网址、网站网址、姓名、岗位、常用电话、备用电话1、备用电话2、性别、生日、微信、钉钉、邮箱、QQ、旺旺、个人传真、淘到客户时间`

## 4. 验收

- 手机号均为 1 开头 11 位
- 至少公司名 + 有效常用电话
- 无座机、无重复公司
- 可直接导入某公司系统

## 5. 归档

- 文件名：`{来源}_清洗结果.xlsx`、`{来源}_分表_01.xlsx` …
- 大批量按约 **1500 条/表** 分表
